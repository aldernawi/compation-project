# منصة إدارة المسابقات

منصة ويب متكاملة مع تطبيق موبايل لإدارة وتنظيم وتقييم المسابقات بطريقة احترافية. تم بناؤها باستخدام Laravel و Inertia.js و React و Tailwind CSS في الواجهة الأمامية، مع تطبيق موبايل مبني بـ Flutter للمشاركين. المنصة تدعم اللغة العربية، العملة بالدينار الليبي (LYD)، واشتراط التسجيل للمشاركة في المسابقات.

## نظرة عامة

**منصة إدارة المسابقات** تغطي دورة حياة المسابقة الكاملة:

1. إنشاء المسابقة وتخصيص نوعها وجوائزها ومواعيدها.
2. فتح باب التسجيل للمشاركين.
3. استلام المشاركات والأعمال من المشاركين.
4. توزيع المشاركات على الحكام وتقييمها.
5. حساب النتائج والترتيب وربط الجوائز.
6. نشر النتائج وإرسال الإشعارات.
7. إصدار تقارير مرجعية للإداريين والمنظمين.

توفر المنصة واجهات مخصصة لكل دور:

- لوحة إدارية للإداري.
- لوحة للمنظم.
- لوحة للحكم.
- لوحة شخصية للمشارك.
- تطبيق موبايل خاص للمشاركين.

### أبرز المميزات

- توطين عربي كامل مع دعم الدينار الليبي (LYD).
- اشتراط تسجيل الدخول للمشاركة في المسابقات.
- أدوار وصلاحيات متعددة.
- REST API للموبايل والتكاملات الخارجية.
- إشعارات فورية عبر FCM.
- إدارة الملفات والمرفقات.
- واجهة أمامية حديثة باستخدام React 19 و Inertia.js 3.

## المميزات الرئيسية

### إدارة المسابقات

- إنشاء مسابقات جديدة مع اسم، وصف، موعد البدء والانتهاء، وشروط التسجيل.
- تصنيف المسابقات بأنواع مخصصة (مثلاً: برمجية، أدبية، تصميم).
- إعداد الجوائز لكل مسابقة (المركز الأول، الثاني، الثالث، ...).
- نشر المسابقة أو إخفاؤها حتى تجهيزها.
- نشر النتائج في وقت محدد.
- دعم المسابقات التي تتطلب تسجيل مسبق.

### المشاركات والتقييم

- المشارك يُقدّم عمله مع مرفقات متنوعة (صورة، PDF، نص، رابط).
- المنظم يراجع المشاركات ويقرر قبولها أو رفضها مع ذكر سبب.
- المنظم يُخصص حكاماً لكل مسابقة.
- الحكم يقيّم المشاركات حسب معايير محددة.
- المنظم ينشر النتائج ويربط الجوائز بالمشاركات الفائزة.

### الجوائز والترتيب

- تحديد جوائز لكل مسابقة.
- ربط الجوائز بالمشاركات الفائزة.
- حساب الترتيب النهائي حسب مجموع النقاط.
- عرض الترتيب للمشاركين بعد نشر النتائج.

### المستخدمين والمصادقة

- أربعة أدوار: Admin، Organizer، Judge، Participant.
- تسجيل دخول، إنشاء حساب، استعادة كلمة المرور.
- تحديث الملف الشخصي وتغيير كلمة المرور.
- دعم رقم الهاتف.
- تعليق أو تفعيل الحسابات من قبل الإداري.
- دعم Passkeys للمصادقة الحديثة.

### التقارير والإشعارات

- تقارير للإداريين والمنظمين.
- إشعارات داخلية للمستخدمين.
- إشعارات فورية عبر FCM.
- إشعارات للنتائج، حالة المشاركات، ومواعيد المسابقات.

### التوطين والعملة

- واجهة عربية بالكامل.
- العملة بالدينار الليبي (LYD).
- تخطيط من اليمين إلى اليسار (RTL).

## المستخدمون والأدوار

تدور المنصة حول أربعة أدوار رئيسية. فيما يلي شرح تفصيلي لكل دور وما يمكنه فعله داخل النظام.

### الإداري Admin

الإداري هو المسؤول الأعلى عن المنصة. يملك صلاحية الإشراف على كل شيء.

**الصلاحيات:**

- عرض لوحة تحكم عامة مع إحصائيات المنصة.
- إدارة المستخدمين:
  - إنشاء حسابات جديدة.
  - تعديل بيانات المستخدمين.
  - تعليق حساب (`suspend`) أو تفعيله (`activate`).
  - حذف المستخدمين.
- إدارة أنواع المسابقات (إضافة، تعديل، حذف).
- إدارة المسابقات (إنشاء، تعديل، حذف).
- إدارة الجوائز المرتبطة بكل مسابقة.
- عرض جميع المشاركات وقبولها أو رفضها.
- عرض نتائج المسابقة وربط جوائز بالمشاركات الفائزة.
- نشر نتائج المسابقة.
- عرض التقارير الإحصائية.

### المنظم Organizer

المنظم هو المستخدم المسؤول عن مسابقة أو مجموعة من المسابقات. يقوم بإعداد المسابقة وإدارتها من البداية إلى النهاية.

**الصلاحيات:**

- عرض لوحة تحكم خاصة تعرض مسابقاته.
- إنشاء وتحرير المسابقات (بدون حذفها نهائياً).
- إضافة وتحرير الجوائز.
- عرض المشاركات المقدمة لمسابقاته.
- قبول أو رفض المشاركة مع ذكر سبب الرفض.
- إدارة الحكام المخصصين لكل مسابقة:
  - إضافة حكم.
  - عرض قائمة الحكام.
  - حذف حكم من المسابقة.
- عرض قائمة المشاركين المسجلين في المسابقة.
- عرض الترتيب والنتائج الأولية.
- إرسال إشعارات للمشاركين المسجلين في المسابقة.
- نشر نتائج المسابقة بعد اكتمال التقييم.

### الحكم Judge

الحكم هو المستخدم الذي يقوم بتقييم المشاركات المقدمة للمسابقات التي عُين عليها.

**الصلاحيات:**

- عرض لوحة تحكم تعرض المسابقات المخصصة له.
- عرض المشاركات التي تنتظر تقييمه.
- فتح صفحة تقييم المشاركة.
- إدخال الدرجات والملاحظات.
- تحديد حالة المشاركة بحاجة لمراجعة إضافية.
- عرض النتائج بعد نشرها.

### المشارك Participant

المشارك هو المستخدم الذي يسجل في المسابقات ويقدم أعماله.

**الصلاحيات:**

- تسجيل حساب جديد وتسجيل الدخول.
- تصفح المسابقات المنشورة.
- عرض تفاصيل المسابقة والشروط والجوائز.
- التسجيل في المسابقة.
- تقديم مشاركة جديدة مع مرفقات (صورة، PDF، نص، رابط).
- تعديل مشاركته قبل انتهاء الموعد.
- متابعة حالة المشاركة (مقبولة، مرفوضة، قيد التقييم).
- عرض النتائج والترتيب بعد النشر.
- عرض الإشعارات.
- تعديل الملف الشخصي وتغيير كلمة المرور.

## مسارات العمل (Workflows)

### مسار المنظم

1. ينشئ المنظم مسابقة جديدة (اسم، نوع، وصف، مواعيد، جوائز).
2. يحدد شروط التسجيل.
3. ينشر المسابقة لتظهر للمشاركين.
4. يختار الحكام المختصين.
5. يراجع المشاركات الواردة ويقبل/يرفض.
6. يُطلع الحكام على المشاركات المقبولة للتقييم.
7. يراجع النتائج وربط الجوائز.
8. ينشر النتائج ويُرسل إشعارات.

### مسار المشارك

1. ينشئ المشارك حساب أو يسجل دخول.
2. يتصفح المسابقات المنشورة.
3. يسجل في المسابقة التي تناسبه.
4. يُعدّ مشاركته ويرفع المرفقات قبل انتهاء الموعد.
5. ينتظر مراجعة المنظم.
6. إذا قبلت مشاركته، تُرسل للحكم للتقييم.
7. بعد نشر النتائج، يستطيع المشارك رؤية ترتيبه وجائزته.

### مسار الحكم

1. يُعيّن الحكم لمسابقة معينة من قبل المنظم.
2. يدخل الحكم إلى لوحته ويرى المشاركات المنتظرة.
3. يفتح صفحة تقييم ويُدخل النقاط والملاحظات.
4. يرسل التقييم.
5. يستطيع لاحقاً الاطلاع على النتائج النهائية.

### مسار الإداري

1. يدخل الإداري إلى لوحة التحكم.
2. يُدير المستخدمين ويتحكم في صلاحياتهم وحالة حساباتهم.
3. يُشرف على المسابقات ويمكنه تعديلها أو حذفها.
4. يراجع جميع المشاركات ويعيد تقييمها إن لزم.
5. ينشر النتائج في أي مسابقة.
6. يطلع على التقارير الإحصائية الشاملة.

1. نسخ ملف البيئة:

   ```bash
   cp .env.example .env
   ```

   ```bash
   php artisan key:generate
   ```

3. تحديث ملف `.env`:

   ```env
   APP_NAME="منصة إدارة المسابقات"
   APP_URL=http://localhost

   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=competition
   DB_USERNAME=root
   DB_PASSWORD=

   FCM_SERVER_KEY=your_fcm_key
   ```

4. بناء الواجهة الأمامية:

   ```bash
   npm run build
   # أو للتطوير
   npm run dev
   ```

## API

تقدم المنصة REST API للموبايل والتكاملات الخارجية، مع مصادقة عبر Laravel Sanctum.

### المصادقة

- `POST /api/register` — إنشاء حساب.
- `POST /api/login` — تسجيل الدخول.
- `POST /api/logout` — تسجيل الخروج.
- `GET /api/user` — معلومات المستخدم الحالي.

### المسابقات

- `GET /api/competitions` — قائمة المسابقات المنشورة.
- `GET /api/competitions/{competition}` — تفاصيل مسابقة.
- `GET /api/competitions/{competition}/results` — نتائج مسابقة.

### المشاركات (تحتاج تسجيل دخول)

- `GET /api/my/submissions` — مشاركات المستخدم.
- `GET /api/submissions/{submission}` — تفاصيل مشاركة.
- `POST /api/competitions/{competition}/submissions` — تقديم مشاركة.
- `PUT /api/submissions/{submission}` — تعديل مشاركة.

### الإشعارات (تحتاج تسجيل دخول)

- `GET /api/notifications` — قائمة الإشعارات.
- `PATCH /api/notifications/{notification}/read` — تحديد كمقروء.

### الملف الشخصي (تحتاج تسجيل دخول)

- `GET /api/profile` — عرض الملف.
- `PUT /api/profile` — تحديث الملف.
- `PUT /api/profile/password` — تغيير كلمة المرور.

لمعرفة جميع المسارات:

```bash
php artisan route:list
```

## تطبيق الموبايل

يوجد تطبيق موبايل مخصص للمشاركين داخل مجلد `mobile/`. التطبيق مبني باستخدام Flutter ويوفر تجربة كاملة للمشارك من التسجيل إلى تقديم المشاركة ومشاهدة النتائج.

### تقنيات الموبايل

| التقنية | الاستخدام |
|---------|-----------|
| Flutter SDK >= 3.6.0 | إطار بناء التطبيق |
| Material 3 | تصميم الواجهة |
| Riverpod | إدارة الحالة (State Management) |
| Dio | إرسال طلبات HTTP |
| go_router | التنقل بين الشاشات |
| SharedPreferences | حفظ توكن المصادقة محلياً |
| flutter_local_notifications | الإشعارات داخل التطبيق |
| image_picker / file_picker | اختيار الملفات والصور |

### شاشات وخواص الموبايل

#### المصادقة

- شاشة تسجيل الدخول.
- شاشة إنشاء حساب جديد.
- شاشة استعادة كلمة المرور.

#### المسابقات

- تصفح قائمة المسابقات المنشورة.
- البحث والفلترة حسب النوع أو الحالة.
- عرض تفاصيل المسابقة (الوصف، الشروط، الجوائز، مواعيد).
- التسجيل في المسابقة.
- عرض النتائج بعد نشرها.

#### المشاركات

- تقديم مشاركة جديدة مع تحديد نوع المحتوى:
  - صورة.
  - ملف PDF.
  - نص.
  - رابط.
- عرض مشاركاتي السابقة.
- عرض تفاصيل المشاركة وحالتها (مقبولة / قيد التقييم / مرفوضة).
- تعديل المشاركة قبل انتهاء الموعد.

#### الإشعارات

- عرض الإشعارات الواردة.
- تحديد الإشعار كمقروء.

#### الملف الشخصي

- عرض البيانات الشخصية.
- تعديل الاسم والبريد ورقم الهاتف.
- تغيير كلمة المرور.


3. عدّل عنوان الخادم في ملف `lib/core/constants/app_constants.dart`:

## النشر

المنصة المقترحة للنشر هي [Laravel Cloud](https://cloud.laravel.com/).

للنشر التقليدي:

1. تثبيت الاعتماديات على الخادم:

   ```bash
   composer install --no-dev --optimize-autoloader
   npm ci
   npm run build
   ```

2. ضبط متغيرات البيئة في ملف `.env` على الخادم.

3. تشغيل الهجرات:

   ```bash
   php artisan migrate --force
   ```

4. تحسين أداء التطبيق:

   ```bash
   php artisan config:cache
   php artisan route:cache
   php artisan view:cache
   ```

5. إعداد خادم الويب (Nginx أو Apache) لخدمة مجلد `public/`.
